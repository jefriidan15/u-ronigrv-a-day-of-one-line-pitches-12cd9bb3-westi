One sentence, 192 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

> Just describe your app idea in plain words and let an AI agent on
> make.fun build a working version you can try today — no coding, no
> cost to start, and nothing to lose if you change your mind.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single
sentence to `/output/entry.txt`. Nothing else is produced.

```sh
node main.ts
cat /output/entry.txt
```
